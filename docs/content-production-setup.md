## 2. 콘텐츠 제작 템플릿

### 카드뉴스 브리프 양식

아래 양식으로 매 카드뉴스 기획 시 작성:

```markdown
# [시리즈명] #[회차] — [제목]

## 기본 정보
- 시리즈: 트렌드 / 가이드 / 신기능 / 후기 / 시즌
- 타겟: (누구를 위한 콘텐츠인가)
- 목표: (이 콘텐츠로 달성하고 싶은 것)
- 스타일 참조: card1 / card2 / card3
- 게시 예정일:
- 채널: Instagram / Facebook / Blog

## 카피 (컷별)
1컷: (타이틀)
2컷:
3컷:
4컷:
5컷:
6컷: (CTA)

## 비주얼 노트
- 컬러 톤:
- 이미지 소스:
- 참조 URL:

## 해시태그
(게시 시 사용할 해시태그)

## 상태
- [ ] 기획 완료
- [ ] 카피 확정
- [ ] 디자인 시안
- [ ] 내부 검수
- [ ] 최종 완성
- [ ] Buffer 업로드
```

## 4. 제작 도구 세팅

### 필수 도구

| 도구 | 용도 | 우선순위 |
|------|------|---------|
| **Canva Pro** | 카드뉴스 디자인, 템플릿 제작 | 즉시 |
| **Figma** (무료) | 상세 디자인, 컴포넌트 관리 | 선택 |
| **Unsplash / Pexels** | 무료 파티 사진 소스 | 즉시 |
| **Remove.bg** | 배경 제거 | 필요 시 |
| **CapCut** | 릴스/숏폼 편집 | 릴스 시작 시 |

### Canva 브랜드 키트 세팅

```
1. Canva Pro 가입
2. 브랜드 키트 생성: "party.it.kr"
3. 브랜드 컬러 등록
4. 브랜드 폰트 등록
5. 로고 업로드
6. 카드뉴스 템플릿 3종 제작 (card1/2/3 스타일)
```

## 5. 콘텐츠 제작 워크플로우

### 주간 사이클

```
월요일: 주간 콘텐츠 기획 확정
  └─ 브리프 작성 (위 템플릿 사용)
  └─ 레퍼런스/사진 소스 확보

화~수: 제작
  └─ 카피 작성 → 검수
  └─ 디자인 제작 (Canva)

목요일: 검수 및 수정
  └─ 최종 검수
  └─ 이미지 Export

금요일: 업로드 및 스케줄링
  └─ Buffer 큐에 다음 주 콘텐츠 업로드
  └─ 해시태그, 캡션 최종 확인

주말: 모니터링
  └─ 게시물 반응 확인
  └─ 댓글 응대
```
