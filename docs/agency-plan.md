# Party.it.kr 마케팅 에이전시 구상안

> 파티 전용 플랫폼 **party.it.kr** 마케팅 자동화 및 카드뉴스 제작을 위한 에이전시 구조

---

## 1. 에이전시 구조 개요

```
[전략 에이전시] ──▶ [콘텐츠 에이전시] ──▶ [배포 에이전시] ──▶ [분석 에이전시]
     │                    │                    │                    │
  마케팅 전략         카드뉴스 제작        Buffer 자동화        성과 측정
  타겟 설정          카피라이팅           스케줄링             KPI 추적
  캠페인 기획        비주얼 디자인        채널 관리            리포트
```

---

## 2. 에이전시별 상세 역할

### Agency 1: 전략 기획 (Strategy Agency)

| 항목 | 내용 |
|------|------|
| **역할** | 마케팅 캠페인 전체 기획 및 방향 설정 |
| **주요 업무** | 타겟 오디언스 정의, 캠페인 캘린더 수립, 경쟁사 분석 |
| **산출물** | 월간 마케팅 플랜, 캠페인 브리프, 타겟 페르소나 |

**핵심 전략 방향:**
- 파티 시즌(연말, 여름, 할로윈 등) 기반 캠페인 사이클
- 2030 타겟 SNS 중심 바이럴 전략
- 파티 호스트 / 참여자 양면 마케팅

---

### Agency 2: 콘텐츠 제작 (Content Agency)

| 항목 | 내용 |
|------|------|
| **역할** | 카드뉴스, 숏폼 영상, 배너 등 크리에이티브 제작 |
| **주요 업무** | 카드뉴스 기획/제작, 카피라이팅, 비주얼 디자인 |
| **산출물** | 카드뉴스 시리즈, 인스타 피드/릴스, 스토리 템플릿 |

**카드뉴스 스타일 가이드 (참조 이미지 분석):**

| 스타일 | 참조 | 적용 시나리오 |
|--------|------|--------------|
| **타이포 중심 (card1)** | 블루 모노톤, 대담한 타이포, 6컷 그리드 | 파티 브랜딩, 무드 전달, 오프닝 공지 |
| **정보형 (card2)** | 미니멀 레이아웃, 아이콘 활용, 교육형 | 파티 팁, 플랫폼 사용법, FAQ |
| **제품/서비스 소개형 (card3)** | 3D 일러스트, 그라데이션, 기능 하이라이트 | 신기능 소개, 서비스 안내, 프로모션 |

---

### Agency 3: 배포 자동화 (Distribution Agency)

| 항목 | 내용 |
|------|------|
| **역할** | Buffer 기반 SNS 자동 배포 및 스케줄링 |
| **주요 업무** | 채널별 포스팅 스케줄 관리, 자동 게시, A/B 테스트 |
| **산출물** | 주간 배포 스케줄, Buffer 큐 관리, 채널별 최적 시간 리포트 |

**Buffer 자동화 구성:**

```
                    ┌─── Instagram Feed
                    │
콘텐츠 제작 완료 ──▶ Buffer ──┼─── Instagram Story
                    │
                    ├─── Facebook
                    │
                    └─── Twitter/X (선택)
```

**채널별 운영 전략:**

| 채널 | 콘텐츠 유형 | 게시 빈도 | 최적 시간 |
|------|------------|----------|----------|
| Instagram Feed | 카드뉴스, 파티 후기 | 주 3-4회 | 12:00, 18:00, 21:00 |
| Instagram Story | 프로모션, 실시간 파티 | 매일 | 상시 |
| Instagram Reels | 숏폼 파티 하이라이트 | 주 2회 | 19:00-21:00 |
| Facebook | 이벤트 공유, 카드뉴스 | 주 2-3회 | 12:00, 20:00 |

---

### Agency 4: 분석 리포팅 (Analytics Agency)

| 항목 | 내용 |
|------|------|
| **역할** | 마케팅 성과 측정 및 인사이트 도출 |
| **주요 업무** | KPI 추적, 전환율 분석, ROI 측정, 개선안 제시 |
| **산출물** | 주간/월간 리포트, 대시보드, 개선 제안서 |

**핵심 KPI:**

| 지표 | 목표 | 측정 도구 |
|------|------|----------|
| 인스타 도달률 | 월 10% 성장 | Buffer Analytics / Instagram Insights |
| 카드뉴스 저장수 | 게시물당 50+ | Instagram Insights |
| 웹사이트 유입 | SNS → party.it.kr 전환 | Google Analytics / UTM |
| 파티 등록 전환율 | SNS 유입 대비 5%+ | party.it.kr 내부 분석 |
| 팔로워 성장률 | 월 15% | Buffer Analytics |

## 3. 워크플로우

```
[1주차]                [2주차]               [3주차]              [4주차]
전략 수립 ──────▶ 콘텐츠 제작 ──────▶ 배포/자동화 ──────▶ 분석/최적화
                                                              │
                                                              ▼
                                                     다음 달 전략 반영
```

### 월간 사이클

1. **1일~5일**: 전략 에이전시 — 월간 캠페인 기획, 콘텐츠 캘린더 확정
2. **5일~15일**: 콘텐츠 에이전시 — 카드뉴스 및 크리에이티브 제작
3. **15일~말일**: 배포 에이전시 — Buffer 스케줄링 및 자동 게시
4. **상시**: 분석 에이전시 — 성과 모니터링, 주간 리포트

## 4. 추천 외부 에이전시/서비스

### 콘텐츠 제작

| 에이전시 | 특징 | 적합도 |
|---------|------|-------|
| **미리캔버스** | 카드뉴스 템플릿 다수, 국내 서비스 | 자체 제작시 활용 |
| **Canva Pro** | 브랜드 키트, 템플릿, 협업 | Buffer 연동 가능 |
| **망고보드** | 한국형 인포그래픽 특화 | 정보형 카드뉴스 |

### 자동화/배포

| 서비스 | 특징 | 비용 |
|--------|------|------|
| **Buffer** | 멀티채널 스케줄링, 분석 내장 | 무료~$120/월 |
| **Later** | 인스타 특화, 비주얼 플래너 | 무료~$40/월 |
| **Hootsuite** | 대규모 관리, 팀 협업 | $99/월~ |

### 분석

| 도구 | 용도 |
|------|------|
| **Google Analytics 4** | 웹 유입 추적, UTM 분석 |
| **Buffer Analytics** | SNS 성과 통합 대시보드 |
| **Hotjar** | party.it.kr 사용자 행동 분석 |

## 5. 카드뉴스 제작 계획

### 시리즈 기획

| 시리즈 | 스타일 참조 | 주기 | 내용 |
|--------|-----------|------|------|
| **파티 트렌드** | card1 (타이포 중심) | 주 1회 | 이번 주 핫한 파티 테마/트렌드 |
| **파티 가이드** | card2 (정보형) | 격주 | 파티 준비 팁, 체크리스트, Q&A |
| **신기능 소개** | card3 (서비스형) | 월 1회 | party.it.kr 업데이트, 기능 안내 |
| **파티 후기** | card1 + UGC | 주 1회 | 실제 파티 사진/후기 기반 |
| **시즌 스페셜** | card1 믹스 | 시즌별 | 할로윈, 크리스마스, 여름 등 |

### 제작 파이프라인

```
아이디어 → 카피 작성 → 디자인 시안 → 내부 검수 → Buffer 업로드 → 자동 게시
```
