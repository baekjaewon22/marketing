| 항목 | 내용 |
|------|------|

## 전략 1: "여성 무료" 바이럴 — 가장 강력한 한 줄

**"파티 공짜로 갈 수 있는 거 알아?"**

이 한 마디가 퍼지면 됩니다. 모든 콘텐츠의 첫 문장은 "무료"를 담아야 합니다.

### 실행

| 콘텐츠 | 후킹 카피 |
|--------|----------|
| 카드뉴스 1컷 | "파티, 돈 내고 가세요? 여기는 **무료**입니다" |
| 릴스 썸네일 | "친구가 알려준 무료 파티 앱" |
| 스토리 | "오늘도 무료 파티 다녀옴 🥂" |
| 블로그 | "여자끼리 무료로 파티 가는 법" |

### 바이럴 포인트
- "무료"는 검색어이자 공유 트리거
- 친구에게 "이거 봐봐" 하게 만드는 콘텐츠
- 의심 → 안전 확인 → 신청 순서를 콘텐츠로 설계

## 전략 2: 카테고리별 타겟 콘텐츠

9개 파티 카테고리 각각이 다른 사람을 끌어들입니다.

| 카테고리 | 타겟 성향 | 콘텐츠 각도 |
|---------|----------|------------|
| **비주얼파티** | 외모에 자신 있는 사람 | "셀카 맛집 파티" |
| **컨셉파티** | 새로운 경험 추구 | "이런 파티 처음이지?" |
| **혼술바** | 혼자 놀고 싶은 사람 | "혼자 와도 괜찮은 곳" |
| **포틀럭** | 요리/음식 관심 | "내가 만든 음식 자랑하는 파티" |
| **도파민파티** | 에너지 넘치는 성향 | "미친 텐션 보장" |
| **소개팅(로테이션)** | 만남 목적 | "한 자리에서 여러 명과 대화" |
| **내향인파티** | 조용한 성향 | "시끄러운 거 싫은 사람 여기요" |
| **와인파티** | 프리미엄 취향 | "무료 와인파티 실화?" |
| **소맥파티** | 캐주얼 음주 | "소맥 한 잔에 새 친구" |

### 실행
- 카테고리당 카드뉴스 1세트 (9종)
- 각 카테고리의 타겟이 쓸 법한 해시태그로 배포
- "나 이 유형인데" → 공유 유도

## 전략 3: 후기/경험 중심 콘텐츠 (신뢰 구축)

여성 타겟에게 가장 중요한 건 **"안전하고 진짜 좋았다"는 증거**.

### 콘텐츠 유형

| 유형 | 형식 | 목적 |
|------|------|------|
| **파티 후기 카드뉴스** | 실제 참가자 후기 + 현장 사진 | 신뢰 구축 |
| **Before/After 릴스** | 가기 전 걱정 → 다녀온 후 반응 | 불안 해소 |
| **Q&A 카드뉴스** | "처음인데 혼자 가도 돼요?" | 진입장벽 제거 |
| **안전 안내** | 파티원의 안전 정책/시스템 | 부모님도 안심 |
| **VLOG형 릴스** | 파티 참가 전 과정 | 실제 경험 공유 |

### 핵심 메시지
```
"처음이라 불안했는데, 진짜 좋았어요"
"혼자 갔는데 친구 3명 생겼어요"
"이게 무료라고?"
```

## 전략 4: 시즌 + 요일별 타겟팅

### 요일별 전략

| 요일 | 콘텐츠 | 이유 |
|------|--------|------|
| 월~화 | 이번 주 파티 미리보기 | 주중 파티 신청 유도 |
| 수~목 | 주말 파티 하이라이트 | 주말 파티 신청 촉진 |
| 금 | "오늘 당장 갈 수 있는 파티" | 당일 신청 유도 |
| 토~일 | 실시간 파티 스토리 | FOMO 자극 |

### 시즌별 전략

| 시즌 | 앵글 |
|------|------|
| 봄 (3~5월) | "봄 분위기 내고 싶을 때 — 무료 와인파티" |
| 여름 (6~8월) | "루프탑 파티 무료로 가는 법" |
| 가을 (9~11월) | "가을 감성 파티 — 혼자 와도 OK" |
| 연말 (12월) | "연말파티 돈 아끼는 법: 파티원" |
| 발렌타인/크리스마스 | "솔로 탈출 프로젝트 — 소개팅 파티" |

## 전략 5: 호스트(B2B) 대상 마케팅

호스트 확보는 플랫폼의 공급 측. 별도 채널로 운영.

### 채널

| 채널 | 콘텐츠 |
|------|--------|
| 네이버 카페 (자영업자) | "파티 인원 모집 고민 해결" 후기 |
| Instagram B2B 계정 (선택) | 호스트 성공 사례 |
| 직접 DM/전화 영업 | 제휴 제안서 |
| 호스트 후기 카드뉴스 | "파티원 도입 후 매출 변화" |

### 핵심 메시지
```
"모집 미달? 30분 안에 여성 참가자 매칭"
"성비 불균형 걱정 끝 — 전국 60곳이 선택한 파티원"
"당일 펑크 나도 걱정 없는 이유"
```

## 전략 6: 진입장벽 제거 콘텐츠

여성 참가자의 가장 큰 허들:

```
1. "진짜 무료야?" → 비용 의심
2. "안전해?"     → 안전 걱정
3. "혼자 가도 돼?" → 사회적 불안
4. "이상한 데 아니야?" → 신뢰 부족
5. "어떤 사람들이 와?" → 참가자 수준
```

### 각 허들별 콘텐츠

| 허들 | 콘텐츠 | 메시지 |
|------|--------|--------|
| 비용 의심 | "파티원 수익 구조 공개" | 호스트 수수료로 운영, 참가자 0원 |
| 안전 걱정 | "파티원 안전 시스템 안내" | 검증된 호스트, 안전 정책 |
| 혼자 가기 | "혼자 간 사람들의 후기" | "혼자 와서 친구 3명 사귐" |
| 신뢰 부족 | "전국 60곳 제휴 호스트" | 검증된 공간, 실제 후기 |
| 참가자 수준 | "파티 현장 사진 공개" | 실제 분위기 보여주기 |
