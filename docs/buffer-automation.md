# Buffer 자동화 구성 가이드

> party.it.kr SNS 마케팅 자동화를 위한 Buffer 세팅 및 운영 가이드

---

## 1. Buffer 초기 세팅

### 계정 구성

```
Buffer 계정
├── Instagram (@party.it.kr)
├── Facebook (Party.it.kr 페이지)
└── Twitter/X (@partyitkr) [선택]
```

### 연동 순서

1. Buffer 가입 (buffer.com) → Pro 플랜 선택
2. Instagram 비즈니스 계정 연결
3. Facebook 페이지 연결
4. 게시 시간 기본값 설정
5. 팀 멤버 초대 (필요시)

## 3. 해시태그 전략

### 기본 해시태그 세트

```
핵심: #파티 #party #파티플랫폼 #partyitkr
카테고리: #홈파티 #생일파티 #기업파티 #베이비샤워 #브라이덜샤워
지역: #서울파티 #강남파티 #홍대파티
감성: #파티준비 #파티데코 #파티룩 #파티플래너
```

### 해시태그 사용 규칙
- 게시물당 20~25개 (Instagram 최적)
- 핵심 5개 + 카테고리 5개 + 지역 3개 + 감성 7~12개
- 월 1회 해시태그 성과 리뷰 후 교체

## 4. 자동화 워크플로우

```
[콘텐츠 제작 완료]
       │
       ▼
[Buffer 큐에 추가]
       │
       ├──▶ 이미지 업로드 (카드뉴스)
       ├──▶ 캡션 입력 + 해시태그
       ├──▶ 채널 선택 (IG/FB/X)
       └──▶ 게시 시간 설정 또는 큐 추가
       │
       ▼
[자동 게시]
       │
       ▼
[Buffer Analytics에서 성과 확인]
```

## 5. UTM 파라미터 규칙

모든 SNS → party.it.kr 링크에 UTM 적용:

```
https://party.it.kr/?utm_source={채널}&utm_medium=social&utm_campaign={캠페인명}&utm_content={콘텐츠ID}
```

| 파라미터 | 규칙 | 예시 |
|---------|------|------|
| utm_source | 채널명 | instagram, facebook |
| utm_medium | 항상 `social` | social |
| utm_campaign | 캠페인명_YYYYMM | trend_202604 |
| utm_content | 콘텐츠 식별자 | cardnews_01 |
