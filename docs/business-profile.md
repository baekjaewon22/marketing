## 비즈니스 모델

### 양면 구조

```
[호스트 - B2B]                              [참가자 - B2C]
주점/식당/공간 운영자                         여성 참가자
     │                                          │
     ├─ 모집 미달 해결                          ├─ 무료 파티 참가
     ├─ 성비 불균형 해소                        ├─ 다양한 파티 선택
     ├─ 당일 펑크 대응                          ├─ 새로운 만남
     └─ 분위기 보강                             └─ 취향별 카테고리
     │                                          │
     └──────── party.it.kr 매칭 ────────────────┘
                     │
              수수료 (서버/마케팅/참가자 지원)
```

### 호스트 측 가치
- 즉각적 인원 충원 솔루션
- 성비 불균형 해소
- 당일 급작스러운 참가자 부족 대응
- 기존 홍보 방식으로 어려운 문제 신속 해결

### 참가자(여성) 측 가치
- **무료** 파티 참가
- 파인다이닝, 소개팅, 컨셉파티 등 다양한 선택지
- 취향에 맞는 파티 필터 검색
- 새로운 사람들과의 만남
