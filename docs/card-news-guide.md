## 1. 참조 이미지 분석

### card1.jpg — 타이포그래피 중심 (무드형)

- **컬러**: 블루 모노톤 (#0055FF 계열) + 크래프트 베이지
- **레이아웃**: 6컷 그리드, 각 컷 독립적
- **타이포**: 대담한 세리프/산세리프 믹스, 큰 활자
- **특징**: 감성적 무드 전달, 텍스트 중심, 이미지 보조
- **적용**: 파티 브랜딩, 무드보드, 시즌 오프닝

### card2.jpg — 정보형 (교육형)

- **컬러**: 화이트 베이스 + 블루/블랙 포인트
- **레이아웃**: 6컷 순차 스토리텔링
- **타이포**: 깔끔한 고딕, 본문 가독성 우선
- **특징**: 아이콘/픽토그램 활용, 번호/단계 표시
- **적용**: 파티 준비 팁, 플랫폼 사용법, FAQ

### card3.jpg — 서비스/제품 소개형

- **컬러**: 그라데이션 배경 (민트/퍼플/블루)
- **레이아웃**: 단일 카드 독립형, 다양한 사이즈
- **타이포**: 간결한 헤드라인 + 서브 텍스트
- **특징**: 3D 일러스트/목업, 기능 하이라이트
- **적용**: 신기능 소개, 프로모션, 서비스 안내

## 3. 시리즈별 제작 가이드

### 시리즈 A: 파티 트렌드 (주 1회)

```
구성: 6컷 캐러셀
1컷: 타이틀 (이번 주 HOT 파티 트렌드)
2컷: 트렌드 키워드 + 비주얼
3컷: 트렌드 상세 설명
4컷: 실제 파티 사례/사진
5컷: party.it.kr에서 활용하는 법
6컷: CTA (지금 바로 파티 만들기 → party.it.kr)
```

- 스타일: card1 참조 (타이포 중심, 무드 강조)
- 톤: 트렌디, 감각적

### 시리즈 B: 파티 가이드 (격주)

```
구성: 6~8컷 캐러셀
1컷: 타이틀 (ex. 홈파티 준비 체크리스트)
2컷: 개요/목차
3~6컷: 단계별 가이드 (번호 매기기)
7컷: 정리/요약
8컷: CTA
```

- 스타일: card2 참조 (정보형, 아이콘 활용)
- 톤: 친절, 실용적

### 시리즈 C: 신기능 소개 (월 1회)

```
구성: 4~5컷 캐러셀
1컷: 타이틀 (새로운 기능 업데이트!)
2컷: 기능 스크린샷/목업
3컷: 사용 방법
4컷: 이런 분께 추천
5컷: CTA
```

- 스타일: card3 참조 (3D 목업, 그라데이션)
- 톤: 깔끔, 신뢰감

## 4. 제작 프로세스

```
Day 1: 기획
  └─ 주제 선정 → 카피 초안 → 레퍼런스 수집

Day 2-3: 디자인
  └─ 시안 제작 (Canva/Figma) → 내부 검수 → 수정

Day 4: 최종화
  └─ 최종 검수 → 이미지 Export → Buffer 업로드

Day 5: 게시
  └─ Buffer 자동 게시 → 성과 모니터링 시작
```

## 5. 카피라이팅 가이드라인

### 톤앤매너

- **친근하지만 세련된**: "파티 준비, 어렵지 않아요!" (O) vs "파티 준비 방법" (X)
- **액션 지향**: "지금 바로 만들어보세요" (O) vs "확인해보세요" (X)
- **이모지 활용**: 타이틀에 1~2개, 본문에 포인트로

### CTA 문구 예시

| 상황 | CTA |
|------|-----|
| 파티 개설 유도 | "나만의 파티, 지금 시작하기 →" |
| 플랫폼 방문 | "더 많은 파티 보러가기 → party.it.kr" |
| 프로모션 | "지금 가입하면 첫 파티 무료!" |
| UGC 유도 | "#partyitkr 태그하고 후기 남기기" |
